Браузерные сценарии проходят реальную обработку PDF/Word/OCR, выбор области
в обеих панелях и скачивание PDF. Транспорт очереди в этих тестах заменён
ограниченным локальным исполнителем. Все девять пар DOC / DOCX / PDF проверены
интеграционными тестами на обезличенных документах.

В матрице подтверждены обязательные проценты, счёт поставщика, добавленная графика
и оба отрицательных контроля. Точное написание адреса и OCR/геометрия одного
автоматического номера требуют ручной сверки. Матрица не исчерпывающая:
precision/recall для всех событий не заявляются. Для реального договора
Word-экспорт отключён из-за ненадёжной логической привязки; оба PDF скачиваются.
Успешный Word-экспорт отдельно проверен на синтетическом документе повторным рендером.

Подробный конфиденциальный отчёт `examples/validation-report.md`, исходные
договоры, матрица, JSON, экспорты и скриншоты остаются только локально и исключены
из Git и Docker build context. SHA256 оригиналов до и после обработки совпадают.

После появления доступа к Docker сценарии подготовки брокера дополнительно
проверены в изолированном Linux-контейнере с read-only filesystem и `noexec` на
tmpfs `/tmp`. Использовался существующий локальный pytest-образ, без сети и
доступа к настоящему брокеру. Из тестовых файлов убраны executable-биты;
исправленный набор использует чтение файлов интерпретаторами.
Дополнительно выполнена настоящая интеграция bootstrap с локальным одноразовым
RabbitMQ 4.1 без портов и сети. Подтверждены создание пользователя, сохранение
пароля со спецсимволами и конечными пробелами, повторный запуск и отказ неверного
пароля. Принудительно зависший RPC прерван по таймауту; временные файлы в `/dev/shm`
удалены. Windows пропускает только POSIX-проверку группы процессов; она прошла на Linux.
Это отдельная проверка CLI;
она не подтверждает соединение приложения с общим брокером aistation.
Полный обновлённый проектный Linux-образ, доступ по `192.168.55.3:8082`,
соединение с production RabbitMQ и корпоративным shared-vlm ещё требуют прогона
на aistation.
Для него используйте команды и ручной список из [эксплуатации](operations.md)
и [тестирования](testing.md). Успех mock-тестов не подтверждает работоспособность
реального брокера. Предупреждения pypdf и Starlette сохранены в логах.
