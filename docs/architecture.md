# Архитектура и границы достоверности

Правила сверены с `Amadu-A/shared_infrasktructure`, main
`8b04d082424245372b54702939cc45b01abe389b`:
[LLM_CONTEXT](https://github.com/Amadu-A/shared_infrasktructure/blob/8b04d082424245372b54702939cc45b01abe389b/docs/LLM_CONTEXT.md),
[Engineering](https://github.com/Amadu-A/shared_infrasktructure/blob/8b04d082424245372b54702939cc45b01abe389b/docs/ENGINEERING_GUIDELINES.md),
[Frontend](https://github.com/Amadu-A/shared_infrasktructure/blob/8b04d082424245372b54702939cc45b01abe389b/docs/FRONTEND_GUIDELINES.md),
[Infrastructure](https://github.com/Amadu-A/shared_infrasktructure/blob/8b04d082424245372b54702939cc45b01abe389b/docs/INFRASTRUCTURE_INSTRUCTIONS.md).

Это модульный монолит: API и Celery-worker используют одну кодовую базу.
`bootstrap.py` собирает зависимости. Направление: web/worker → application → domain;
адаптеры реализуют application ports. Домен не импортирует FastAPI, PDF, SQLite или Celery.
SQLite хранит только временные метаданные; документы и результат лежат в UUID-каталогах.
Захват queued → processing и квоты атомарны. Повторная доставка не запускает второе сравнение.
Результат публикуется только при действующей аренде и отсутствии отмены.

Модель разделяет `DocumentVersion`, структурные `DocumentElement` с видами
section/paragraph/list_item/cell, `TextRun`, `Word`, `GraphicElement`, `SourceAnchor`,
`VisualRegion`, `ElementMatch`, `Difference`, `CoverageReport`, `VerificationFinding`,
`ExportArtifact`, `ComparisonJob`. Вложенные ячейки сохраняют OOXML path и родительский
контекст. Координаты — пункты от верхнего левого угла видимой страницы, после учёта
CropBox/Rotate. Нативные PDF дают посимвольные области; OCR даёт области слов.

Конвейер:

1. Magic/type, целостность, лимиты файла/страниц/архива/XML; запрет макросов и внешних ресурсов.
2. Итоговая Word-копия с принятием поддерживаемых исправлений, изолированный LibreOffice-профиль.
3. Отдельный безопасный PDF-просмотр. Оригинальные байты не изменяются.
4. Постраничная оценка текста, растра и покрытия видимых чернил; OCR при недостатке слоя.
5. Две конфигурации OCR, отдельное чтение спорных чисел, обратное преобразование координат.
6. Структурные опоры Patience, редкие Histogram-опоры, линейное по памяти локальное LCS/Myers.
7. Rolling hash/Rabin–Karp с проверкой содержимого для перемещений; n-граммы для кандидатов.
8. Ограниченный Smith–Waterman, взвешенное венгерское назначение и split/merge соответствия.
9. Myers по локальным токенам; Damerau–Levenshtein уточняет короткие символьные изменения.
10. pHash выбирает графические кандидаты, SSIM измеряет локальное сходство после масштаба;
    точный отпечаток проверяется отдельно. Большое сходство не означает идентичность.
11. Классификация каждого текстового узла, явные пробелы покрытия и геометрии.
12. Независимые полный и адресный проходы shared-vlm: все пакеты, ограниченная конкуренция,
    JSON Schema/Pydantic, локальные доказательства, checkpoint и повтор без OCR.
13. Отдельные PDF и безопасные Word-экспорты с повторным рендером.

Статистика считает уникальные подтверждённые события. `total` исключает
`ambiguous_match`, `unverified_region` и неподтверждённые замечания ИИ. Неподтверждённые OCR-события
сохраняют тип предполагаемого изменения и отдельно входят в `unverified`.
Событие может быть одновременно предполагаемым изменением и непроверенным участком.
Подтверждённые алгоритмические факты не удаляются. Разрешение неопределённости
требует независимых текстовых и структурных доказательств, согласованной геометрии
и визуального ответа ИИ. Противоречия сохраняются отдельно.
У корневой неопределённости один счётчик; общее предупреждение того же блока
не дублирует уже показанное предполагаемое изменение.
Скрытие непроверенных областей меняет только проекции и варианты экспорта.
Планы, промпты, счётчики и правила объединения описаны в [ИИ-проверке](ai-review.md).

Подписанный PDF определяется по объектам `/Sig`, `/ByteRange`, `/Contents`.
В этом случае обе стороны проходят визуальный OCR, без доверия скрытому тексту.
Экспорт — отдельная неподписанная визуальная копия. Проверка сертификата не выполняется.

Для произвольных сканов не гарантируется отсутствие ошибок OCR. Особенно сложны
перекрытые печатями слова, мелкая пунктуация, смешанные алфавиты и границы таблиц
без линий. Геометрия OCR не выдаётся за точные границы символов. Некоторые сложные
OOXML-исправления и altChunk явно отклоняются. При ненадёжной геометрии Word-экспорт
отключается с причиной. Полная реконструкция всех произвольных диаграмм, формул и
рукописного текста не подтверждена; такие документы требуют ручной проверки.

Просмотрщик использует ленивые серверные PDFium-растры вместо PDF.js: одна страница
на панель, координатный слой, поиск по извлечённому тексту/OCR, масштаб и поворот.
Это исключает CDN и передачу скрытого текста подписанного PDF как доказательства.
Связанные переходы вычисляются по сопоставленным элементам. Равенство номеров
страниц не используется как доказательство соответствия.
